Progetto-settimana-7


SportsHub ⚽️

Applicazione web per cercare squadre sportive, vedere i dettagli e salvare le preferite.

## Funzioni

- Cerca una squadra per nome
- Mostra stemma, informazioni ed eventi
- Aggiungi e togli dai preferiti
- Tema chiaro e scuro

## Tecnologie

- HTML
- CSS (con variabili CSS per il tema chiaro e scuro)
- JavaScript (DOM, eventi, `fetch`)
- Bootstrap 5
- [Nome dell'API usata]

## Come si usa

1. Scrivi il nome di una squadra nella barra di ricerca.
2. Clicca su una card per vedere i dettagli e gli ultimi eventi.
3. Premi il pulsante dei preferiti per aggiungere o togliere la squadra.
4. Cambia tema chiaro/scuro dal pulsante in alto.

## Cosa ho usato

- Usare `fetch` e `async/await` per leggere dati da un'API
- Creare elementi HTML con JavaScript
- Gestire eventi e stati dei pulsanti
- Usare le variabili CSS per i temi
